# Independent second AI-pass annotation — GPT-6 (OpenAI ChatGPT)

**Performed:** 2026-11-15, this ChatGPT session. **Scope:** exactly 140 preselected Phase 5 development-review IDs. **Annotator:** GPT-6 through ChatGPT, not a human; Claude Sonnet 5.5 annotated the original sheets. This is a second AI provider's judgment, not independent human ground truth. The two models may share broad training data or biases. Do not use these cases as a final held-out set.

**Blindness:** the annotator saw each original **full** `review_text` and a shortened product title from `annotation/dev_pool_sheet.csv` or `annotation/neutral_candidate_pool.csv`. Existing Claude labels, model predictions, stars and gold references were **not** opened for these IDs before this file was authored. The annotator was aware the *selection* targeted ambiguity strata, so this is not a random population sample. The ChatGPT system had context on Phase 4's general findings, but not Claude's per-ID reference labels.

**Annotation instructions used:** Read complete source review text and title. Follow frozen `annotation_policy.md` v1: Positive for clear favorable evaluation, Negative for dissatisfaction or defects, Neutral for no personal or clear evaluative opinion and standalone lukewarm phrasing, Mixed when substantial positive and negative opinions coexist without dominance, Unclear when uninterpretable. Use `mixed` tag if one polarity dominates a mixed review; `delivery-only` for comments only about delivery or seller; `no-opinion` on Neutral no-experience or informational comments. Star ratings hidden. Never infer an opinion solely from the product title. Treat subjective praise in marketplace-style tag lists as **possible positive evaluation** but set low confidence if the list may be a buyer-selected or platform-generated template; avoid assuming all tag lists are neutral. Record concise reasons and low confidence at disputed boundaries. Never overwrite Claude's labels. Each decision was authored from reading the actual review, not copied from Claude.

**Limits:** Tag-list endorsement status cannot be verified from the text alone; some labels are ambiguous under S4. This sample intentionally oversamples difficult cases and is not representative. No adjudicator reviewed disagreements; never call it a gold reference. Model/version GPT-6 (ChatGPT). No separate prompt to an external model was run. No second human involvement. Once this file is committed, a separate scorer may reveal original Claude labels and compute descriptive agreement.
