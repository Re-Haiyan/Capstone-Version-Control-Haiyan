# Experiment log

Dataset versions: `train_v3` (3,946 high-confidence rows, 303 products), `test_v3` (846 rows, 82 products, historical). Annotation policy: v1 (in force); v2 is only a proposal. Code version: branch `research-improvements` (base `831f22f`). Cross-validation: product-grouped 5-fold, seed 0 unless stated. Rare flags were checked per fold (safety 15 to 16 positives per fold, counterfeit 20 to 37).

| ID | Hypothesis | Setup | Result | Decision |
|---|---|---|---|---|
| E00 | The existing splits leak | `data_audit.py` | No product overlap, no cross-split duplicates, no near-duplicates (cos >= 0.90). 343 repeated texts inside training (templates), no conflicting duplicates. | Documented; folds are product-grouped |
| E01 | Sparse text models are competitive (Experiment A) | 18 configurations (word / char / both, context prefix on/off, C 1/4/16), one logistic regression per flag, class weights, one threshold per flag on out-of-fold predictions | Best word+char, no context, C=4: macro F1 0.645 (CV). Context prefix hurt (0.616). Historical test: defect 0.65, counterfeit 0.88, safety 0.40, not-as-advertised 0.66, quality 0.68, delivery 0.50 | Kept as a baseline; not adopted |
| E02 | Frozen multilingual embeddings beat sparse features (Experiment B) | e5-small and MiniLM, four input variants, C 0.5/2/8, with and without structured features | Embeddings alone 0.37 to 0.53 macro F1 (worse than E01). With structured features including the tuned rule flags 0.71; this reflects the rules, not the embeddings | Rejected |
| E03 | SetFit / larger models / distillation (Experiments C, D, E) | not run | The prerequisite (a competitive embedding baseline) was not met | Not run, reason recorded |
| E04 | Fusing the rules and the sparse model helps | rules OR / AND model, thresholds from out-of-fold predictions, strategy picked on the validation slice (rules kept unless a fusion wins by 0.03) | Selected macro F1 0.715 against the rules' 0.722; defect picked the sparse model on validation, worse on test (0.65 against 0.69); intervals include zero | Rejected |
| E05 | A regularised stacker over rule decision + out-of-fold sparse probability helps | one logistic regression per flag, C in {0.1, 1}, 3 features + group | Test F1 defect 0.71, counterfeit 0.96, safety 0.53, not-as-advertised 0.76, quality 0.74 against the rules' 0.69, 0.94, 0.53, 0.72, 0.73; all paired intervals include zero (counterfeit 0.00 to +0.06) | Inconclusive; not adopted (adds a model dependency without proven gain) |
| E06 | Weak labels from the rules help a model (Part 7) | 250 labeling functions from the addition files, precision-weighted vote, +500 / +2,000 weakly labelled unlabelled reviews | CV macro F1: gold only 0.625, +500 0.620, +2,000 0.623; 816 correlated pairs | Rejected; gold-only retained |
| E07 | Active-learning selection beats random (Part 12) | simulation on the labelled pool, 5 seeds, +100/+200/+400 rows after a 500-row start, product-disjoint evaluation | At +100: random 0.447, uncertainty 0.493, disagreement 0.533, mix 0.501; at +400: random 0.490, mix 0.569 (sd 0.015 to 0.057) | Retained: strategies beat random by more than the seed spread; caveat: disagreement uses error-tuned rules, so it is optimistic |
| E08 | The sentiment model can be recalibrated cheaply | logistic regression on the model's probabilities + stars (+ text) | CV macro F1 0.605 -> 0.622 (probs + stars) -> 0.718 (+ text); historical test 0.570 -> 0.593 -> 0.717 | Retained as an opt-in module, not wired by default |
| E09 | Labels contain recoverable noise | cleanlab on out-of-fold probabilities (sparse + e5 average), per flag | 192 suspected issues (129 high priority): defect 51, not-as-advertised 69, quality 38, safety 14, delivery 19, counterfeit 1 (flag-level counts, one row can appear under two flags). A mix of genuine label errors and model misses | Queue for human adjudication only |
| E10 | Single thresholds per flag are stable | 300 product-bootstrap resamples | Narrow spreads (for example defect 0.40/0.45/0.45) | Single threshold per flag is adequate |
| E11 | Evidence spans are valid | `evidence_check.py` over 4,792 reviews | 1,912 spans, 0 invalid; flags without a span: defect 111, not-as-advertised 22, quality 21, safety 1 | Documented; model-only flags have no quote |
| E12 | Regression matrix finds bugs | 23 cases, English/Filipino/Taglish | One failure: "akala ko peke pero original pala" flagged counterfeit | Fixed with a review-level guard (no change in any score) |
| E13 | Deployment cost is acceptable | `bench_deploy.py` on the VM | 62 ms median per review, 14.4 reviews/s, 377 MB peak, 2.3 s cold start | Within constraints |

Earlier work in this session (previous rounds): rule tuning on the training rows (not-as-advertised 0.59 to 0.72, defect 0.67 to 0.68 on test), three fine-tuned XLM-R runs (`training/RESULTS_v1.md`). Seeds: every stochastic step used a fixed seed; the XLM-R runs had one seed each and were unstable between runs, so no single-run claim is made from them.

Not run, with reasons: SetFit, LoRA, distillation (E03); product-conclusion accuracy and inter-annotator agreement (need human annotation); a fresh final test (needs new labelled data).
